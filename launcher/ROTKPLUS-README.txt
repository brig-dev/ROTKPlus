ROTKPlus - The Lord of the Rings: The Return of the King (PC, 2003), ready to play
====================================================================================

One download with everything: the ROTKPlus launcher, ROTK Fix (widescreen, modern renderer, controllers, 3D audio,
texture packs) and the ROTKPlus mod (co-op for 3 and 4 players, Versus, more enemies and allies, the players' names and
statistics). For the PC game, version 1.0. Nothing of the game is included: you need your own copy.

Install
-------
1. Install the game (version 1.0) in a folder of its own, for example C:\Games\ROTK.
2. Unzip this package in another folder, for example C:\Games\ROTKPlus (never inside the game's folder).
3. Start ROTKPlus.exe, choose the game's folder, and press Play: the first Play puts ROTK Fix and ROTKPlus in the game's
   folder, next to rotk.exe (the game's own files are not changed).
4. Settings: the tabs of the launcher. ROTKPlus' own are on the ROTKPlus tab and, in the game, on the Multiplayer page.

If ROTKPlus was installed before as DivxMediaLib.dll in the game folder, take that out: delete DivxMediaLib.dll and
rename DivxMediaLib_orig.dll to DivxMediaLib.dll (with the game closed). Your ROTKPlus.ini and statistics stay.

Steam Deck and SteamOS: add ROTKPlus.exe to Steam as a non-Steam game, with a recent Proton.

Problems: https://github.com/brig-dev/ROTKPlus/issues (attach the newest file of ROTKPlus_logs and ROTKFix.log from the
game folder).
